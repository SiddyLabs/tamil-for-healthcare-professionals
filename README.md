# Tamil for Healthcare Professionals

Interactive Tamil learning tool designed for doctors, medical students, nurses and healthcare professionals working in Tamil-speaking regions.

Created by **Dr. Siddharth Bableshwar**

## Live Website

https://siddylabs.github.io/tamil-for-healthcare-professionals/

## Features

- Tamil → English mode
- English → Tamil mode
- Beginner difficulty
- Intermediate difficulty
- Advanced difficulty
- Custom question count
- Immediate answer feedback
- Mistake review after each session
- Smart category-based distractors

## Clinical Content

### Vocabulary

- Body Parts
- Symptoms
- Swelling
- Diseases

### Examination Instructions

- Common commands used during physical examination

### History Taking

- General History
- Past History
- Treatment History
- Family History

### Specialty Sections

- Cardiology
- Pulmonology
- Menstrual History

## Purpose

This project aims to help healthcare professionals rapidly acquire practical spoken Tamil for day-to-day patient interactions.

The focus is on communication that is immediately useful in outpatient clinics, wards, emergency departments and specialty practice.
